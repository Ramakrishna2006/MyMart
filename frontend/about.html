ℹ️ How My Mart works

My Mart is a full-stack online grocery store: a Flask REST API (backend) talks to a SQLite database, and a HTML/CSS/JavaScript frontend calls that API with fetch(). Everything runs on your own computer at http://localhost:5000.

The same Flask server also serves the frontend files, so there is only one thing to start.

🛍️ Customers can

  • Register / log in (passwords are hashed)
  • Search, filter by category, veg-only, in-stock; sort by price, rating, discount
  • Add to cart, change quantities (stock is checked)
  • Checkout with UPI QR code or Cash on Delivery
  • Track orders through Placed → Packed → Shipped → Delivered and cancel early orders

🛠️ Admins can

  • See revenue, orders, customers and average order value
  • Analyse sales by month, category, product, city, weekday and payment method
  • Add, edit and remove products; restock low-stock items
  • Move orders through the delivery workflow
  • View every customer and how much they spent

📊 Anyone can

  • Open the Dataset explorer
  • Read what each of the 5 sets means, column by column
  • See live statistics and charts per set
  • Search the rows and download them as CSV
